# 🖥️ MONTA.SYS — Monte a Máquina

> Quebra-cabeça interativo e educativo para aprender, de forma prática, onde ficam os principais componentes de um computador e compreender suas funções.

## 🎯 Sobre o projeto

O **MONTA.SYS** é um jogo educativo desenvolvido para a disciplina de **Arquitetura de Sistemas**, destinado aos alunos do **2º ano do Ensino Médio em Tempo Integral (EMTI)**.

A proposta é transformar o estudo dos componentes internos de um computador em uma atividade prática e interativa.

Durante o jogo, o aluno precisa identificar cada componente e encaixá-lo corretamente em sua posição dentro da representação de um computador.

Além de trabalhar a localização das peças, o jogo apresenta informações sobre a função desempenhada por cada componente.

---

## 🧩 Como funciona

O jogador recebe diferentes componentes de hardware e precisa posicioná-los corretamente no computador.

São trabalhados os seguintes componentes:

* 🧠 **Processador (CPU)** — executa instruções e realiza os cálculos do computador;
* ❄️ **Cooler / Dissipador** — auxilia no resfriamento do processador;
* 💾 **Memória RAM** — armazena temporariamente os dados que estão sendo utilizados;
* 🎮 **Placa de Vídeo (GPU)** — responsável pelo processamento de imagens e gráficos;
* 💽 **Armazenamento (SSD/HD)** — mantém arquivos e o sistema operacional armazenados;
* ⚡ **Fonte de Alimentação** — converte e distribui energia para os componentes.

O projeto também utiliza **dois módulos de memória RAM** durante a montagem.

---

## 🎮 Recursos do jogo

### 🧩 Montagem interativa

As peças podem ser selecionadas e posicionadas nos espaços correspondentes.

O jogo também possui suporte à interação por **arrastar e soltar**, tornando a atividade semelhante a um quebra-cabeça digital.

### 📚 Informações educativas

Ao selecionar uma peça, o aluno pode visualizar:

* nome do componente;
* função desempenhada no computador;
* informações que auxiliam na identificação da peça.

### 🎯 Sistema de pontuação

O desempenho do jogador é acompanhado durante toda a atividade.

* **+100 pontos** por componente instalado corretamente;
* **-20 pontos** por tentativa incorreta;
* **-30 pontos** ao utilizar uma dica.

Ao finalizar a montagem, o jogo apresenta:

* tempo utilizado;
* pontuação final;
* quantidade de erros;
* quantidade de dicas utilizadas.

De acordo com o desempenho, o jogador recebe uma classificação.

### ⏱️ Cronômetro

O tempo começa somente quando o jogador inicia a montagem e é contabilizado até que todos os componentes sejam posicionados corretamente.

---

## 📊 Níveis de dificuldade

O MONTA.SYS possui três níveis:

### 🟢 Fácil

Fornece maior apoio visual para identificação das peças e dos locais de instalação.

### 🟡 Médio

Mantém informações intermediárias para auxiliar o jogador durante a montagem.

### 🔴 Difícil

Reduz as pistas visuais, exigindo maior conhecimento sobre os componentes e suas respectivas posições.

Alterar a dificuldade reinicia a partida.

---

## 🎨 Temas visuais

A interface possui três opções de tema:

* **Circuito** — interface escura inspirada em placas e circuitos eletrônicos;
* **Terminal** — visual inspirado em terminais de computador;
* **Oficina** — interface clara inspirada em ambientes técnicos.

A mudança de tema não interfere no funcionamento da atividade.

## 🎓 Aplicação pedagógica

O projeto foi elaborado como recurso didático para a disciplina de **Arquitetura de Sistemas**, com alunos do **2º ano do EMTI**.

A atividade pode ser utilizada para:

* introduzir os principais componentes de hardware;
* revisar conteúdos sobre arquitetura de computadores;
* relacionar componentes às suas respectivas funções;
* trabalhar a localização física dos componentes;
* realizar atividades práticas antes ou depois de aulas teóricas;
* estimular a aprendizagem por meio da gamificação.

O objetivo não é simular todos os detalhes técnicos envolvidos na montagem real de um computador, mas oferecer uma representação didática que facilite a compreensão dos principais componentes.

---

## 💻 Tecnologias utilizadas

O projeto foi construído utilizando:

* **HTML5** — estrutura da aplicação;
* **CSS3** — interface, temas, responsividade e animações;
* **JavaScript** — lógica do jogo, pontuação, cronômetro, níveis, dicas e interações.

Não é necessário instalar bibliotecas ou frameworks JavaScript para executar o jogo.

---

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Localize o arquivo HTML principal.
3. Abra o arquivo em um navegador moderno.
4. Escolha o nível de dificuldade e o tema.
5. Clique em **Iniciar montagem**.
6. Posicione cada componente no local correspondente.
7. Complete a máquina e confira seu desempenho.
